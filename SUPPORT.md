## How to ask for help

Open an issue and include:

- operating system;
- Blender version;
- Python version, when relevant;
- script path;
- command or action used;
- console output;
- expected result;
- actual result.

## Documentation first

Read these files before opening an issue:

- `README.md`
- `docs/README.md`
- `docs/PROJECT_OVERVIEW.md`
- folder-specific README files
