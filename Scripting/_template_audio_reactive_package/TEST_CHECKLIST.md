# Test Checklist

## Preparation

- [ ] Package copied from template to a real project folder.
- [ ] `config.py` updated.
- [ ] Audio path configured.
- [ ] JSON summary path configured.
- [ ] Output path configured.
- [ ] Blender version documented.

## Blender execution

- [ ] `main.py` opens without syntax errors.
- [ ] Script can run from a clean scene or documents required preconditions.
- [ ] Scene objects are created.
- [ ] Materials are assigned.
- [ ] Camera is created or selected.
- [ ] Lights are created or selected.
- [ ] Frame range is set correctly.
- [ ] Audio is loaded or documented as external.
- [ ] Console output reviewed.

## Render

- [ ] Render settings are explicit.
- [ ] Output directory exists or is created.
- [ ] Short render test completed.
- [ ] Rendered frames reviewed.

## Encoding

- [ ] FFmpeg executable found or configured.
- [ ] Image sequence path configured.
- [ ] Audio path configured.
- [ ] Frame rate configured.
- [ ] Output video path configured.
- [ ] CPU/GPU profile documented.
- [ ] Short encoding test completed.

## Final report

- [ ] `REPORT.md` updated.
- [ ] Known issues documented.
- [ ] Next improvements documented.
