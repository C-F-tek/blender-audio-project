# Scripting

This folder contains Blender Python scripts and versioned implementation areas.

## Purpose

Scripts in this folder are expected to create, tune, or automate Blender scenes.

## Guidelines

- Keep script inputs documented.
- Keep local paths configurable.
- Avoid deleting generated data from scripts unless explicitly intended.
- Add comments for Blender API compatibility-sensitive sections.
- Prefer modular helpers when a script grows large.

## Versioned folders

Versioned folders such as `v61b/` represent development snapshots or workflow iterations.
