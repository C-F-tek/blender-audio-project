# Code of Conduct

## Purpose

This project is a technical workspace for Blender scripting, audio-reactive visual generation, AI-assisted package development, and related tooling.

The goal of this document is to keep collaboration clear, professional, and productive.

## Expected behavior

Participants are expected to:

- communicate with technical clarity;
- keep discussions focused on the repository, code, documentation, and workflows;
- provide actionable feedback;
- document assumptions and limitations;
- respect maintainers' decisions about project direction and scope.

## Unacceptable behavior

The following behavior is not acceptable in project discussions, issues, pull requests, or code review:

- personal attacks;
- harassment;
- intentionally disruptive comments;
- disclosure of private information without permission;
- repeated off-topic discussion after a maintainer asks to stop;
- destructive changes submitted without clear technical justification.

## Maintainer responsibilities

Maintainers may:

- ask contributors to revise unclear issues or pull requests;
- close off-topic or low-quality issues;
- request tests or documentation before merging;
- reject changes that increase technical risk without sufficient benefit;
- remove comments that prevent productive technical review.

## Scope

This code of conduct applies to repository interactions, including issues, pull requests, reviews, discussions, and documentation contributions.

## Enforcement

Enforcement actions may include a warning, request for revision, temporary restriction, or removal of participation depending on severity and project impact.
