# Tools/npu/dual_ai_pipeline context

## Role

`Tools/npu/dual_ai_pipeline` contains the NPU-side dual-AI pipeline entrypoint used by local Blender/audio/AI workflows.

It is an application-support pipeline, not the central IA-Carmine heap runtime.

## Responsibilities

- Coordinate dual-AI pipeline execution where explicitly invoked.
- Consume music/code/manual context packets generated by provider-mesh tools.
- Produce structured pipeline output for review or downstream workflow use.

## Representative commands

Use through the NPU dispatcher:

```powershell
python -m Tools.npu run_dual_ai_pipeline ...
```

## Output role

Outputs are local pipeline artifacts and review inputs. They are not source changes by themselves.
