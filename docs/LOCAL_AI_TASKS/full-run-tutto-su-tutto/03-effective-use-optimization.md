# Effective use optimization

Questa lane produce qualità concreta prima della run reale.

## Obiettivo

Usare davvero i tool locali già costruiti:

- SQLite FTS5;
- namespace memory;
- runtime tool telemetry;
- provider hardening;
- GPU/Ollama/NPU readiness.

## Output qualitativo

Il workflow genera:

```text
full0to10_effective_use_quality_product.md
```

Il prodotto nasce da una richiesta al tool e da ricerca SQLite, non da provider
generation.

## Regola

Ogni prodotto qualitativo deve dichiarare:

- request originale;
- memory DB/namespace;
- evidence retrieval;
- contratti GPU/NPU/Ollama;
- next actions.
