# Repo quality packet

Il Full0To10 deve produrre qualità leggendo il progetto reale.

## Input

Qualsiasi file o directory:

- Markdown;
- Python;
- JSON;
- PowerShell;
- testo configurativo.

## Output

Qualsiasi file controllato, preferibilmente sotto `output/**`.

## Policy

Non esegue codice letto in input. Non esegue provider. Produce evidence.
