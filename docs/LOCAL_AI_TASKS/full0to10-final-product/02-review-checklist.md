# Review checklist

Prima di usare il pacchetto come base per una run reale:

## SQLite FTS5

- DB generato sotto `output/**`;
- namespace dichiarato;
- search results presenti;
- quality product cita la request;
- nessun DB committato.

## Runtime tools

- telemetry JSON presente;
- eventi tool >= 4;
- errori vuoti o spiegati;
- capability/contract allegati.

## GPU/Ollama

- ruolo dichiarato come explicit primary advisory;
- nessuna generation implicita;
- workload quality validator disponibile;
- quality stack eseguito prima.

## NPU/OpenVINO

- ruolo dichiarato come sampled auditor/diagnostic;
- nessuna promozione primaria automatica;
- GPU.0 dichiarata secondary/diagnostic.

## Readiness

- product review può passare;
- real provider run resta separata;
- blocker visibili.
