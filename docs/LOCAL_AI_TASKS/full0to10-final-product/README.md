# Full0To10 final product

Questa directory descrive il prodotto finale del tool Full0To10.

## Scopo

Il prodotto finale non è un singolo report. È un pacchetto composto da:

- richiesta operativa;
- evidence SQLite FTS5;
- telemetry runtime tool;
- provider contracts;
- readiness;
- manifest;
- output Markdown leggibile.

## Posizione nel workflow

```text
quality stack
-> effective use optimization
-> final product package
-> review
-> eventuale run provider reale
```

Il pacchetto non autorizza automaticamente una run provider.
