# Next run usage

Il pacchetto prodotto finale deve essere incluso nella prossima run come evidence.

## Input consigliato

```text
output/validation/full0to10_final_tool_product/full0to10_final_tool_product_manifest.json
output/validation/full0to10_final_tool_product/full0to10_final_tool_product.md
```

## Uso operativo

1. generare il pacchetto;
2. leggere readiness;
3. verificare blocker;
4. includere evidence nel bundle;
5. decidere se abilitare provider reali.

## Regola

La run reale deve derivare da evidence prodotta dai tool, non da intuizione.
