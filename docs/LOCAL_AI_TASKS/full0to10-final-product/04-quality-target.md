# Quality target

Il target qualitativo del tool Full0To10 è produrre output utili a decisioni
operative.

## Output povero

Un output è povero se contiene solo:

- testo generico;
- checklist non legata a evidence;
- nessun path;
- nessun manifest;
- nessuna telemetry;
- nessuna readiness.

## Output buono

Un output è buono se contiene:

- request originale;
- artifact paths;
- evidence index;
- contratti provider;
- SQLite search results;
- tool telemetry;
- readiness score;
- next actions.

## Output finale

Il prodotto finale deve permettere a un'altra AI o a un operatore umano di capire:

```text
cosa è stato chiesto
quali tool hanno lavorato
quali prove sono state prodotte
quali provider sono ammessi
cosa manca prima della run reale
```
