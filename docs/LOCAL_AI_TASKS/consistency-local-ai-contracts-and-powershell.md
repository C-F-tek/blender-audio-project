# Local AI Entrypoint: Consistency Review for Local AI Contracts and PowerShell Runners

This is a non-interactive task file for a local AI runner.

The purpose is to let the local AI pipeline compare the repository contract documents with the PowerShell runner scripts and produce a consistency report plus safe proposals. This task is intended to be generated by the master AI and executed by the local AI/NPU/GPU pipeline.

## Absolute first instruction

Before planning, editing, validating, opening a PR or generating proposals, read and obey these files in order:

```text
AGENTS.md
docs/LOCAL_AI_RUN_BOOTSTRAP.md
```

Then read this task file again and continue from the task contract below.

If the local AI cannot read `AGENTS.md` or `docs/LOCAL_AI_RUN_BOOTSTRAP.md`, it must stop and report the missing file. It must not infer their contents.

## Task classification

```text
validation/evidence + docs/workflow-state + report-only consistency review
```

Default provider execution:

```text
allowed only when explicitly requested by the wrapper flags
```

Patch application:

```text
forbidden
```

The local AI must not apply patches. It may only produce report-only outputs, repository proposals and, if explicitly requested later, inert draft patch specs.

## Required consistency checks

The local AI must evaluate whether the docs and scripts agree on these contracts:

```text
1. AGENTS.md remains the primary repository contract.
2. docs/LOCAL_AI_RUN_BOOTSTRAP.md is read before local task execution.
3. docs/LOCAL_AI_TASKS/*.md files are valid non-interactive entrypoints.
4. run_local_ai_markdown_task.ps1 only prepares packets and delegates runner execution.
5. run_local_ai_task_via_pipeline.ps1 remains report-only/proposal-only by default.
6. Multistep provider workflow is explicit only via -RunMultistepProviderWorkflow.
7. Provider execution is explicit only; no implicit GPU/NPU execution.
8. Ollama/GPU is primary advisory only behind quality gate.
9. OpenVINO/NPU remains probe / guardrail / decode diagnostic.
10. No automatic patch apply.
11. No automatic merge.
12. Compact evidence belongs under docs/LOCAL_VALIDATION_EVIDENCE/.
13. Full generated reports stay under ignored output/.
14. Large MD/code/heavy artifact work should prefer multistep mode.
15. PowerShell examples must not contain literal placeholder paths such as <run> or <task> in copy-paste runnable commands.
```

## Required output from the local AI

The local pipeline must produce a repository proposal report that includes:

```text
summary
consistent_items
inconsistencies
ambiguous_items
safe_doc_update_proposals
safe_script_update_proposals
validation_recommendations
risk_notes
```

Each proposal must include:

```text
target_file
change_type: docs_only | script_comment_or_example | validator_needed | follow_up_task
reason
evidence_source_files
risk_level: low | medium | high
apply_allowed_now: false
```

The local AI must mark every proposed change as manual-review only.

## Recommended execution command

Run through the project-owned local wrapper and adapter:

```powershell
python -m Tools.workflow run_local_ai_markdown_task `
  -TaskFile .\docs\LOCAL_AI_TASKS\consistency-local-ai-contracts-and-powershell.md `
  -TaskBranch codex/consistency-local-ai-contracts `
  -RunnerCommand 'python -m Tools.workflow run_local_ai_task_via_pipeline -PromptFile "{PROMPT_FILE}" -TaskFile "{TASK_FILE}" -RunDir "{RUN_DIR}" -Profile npu -RunMultistepProviderWorkflow -RunOllamaProbe -RunNpuProbe -UsePrimaryAdvisoryProvider -BuildEvidence -Basename consistency_local_ai_contracts -ProposalBasename consistency_local_ai_contracts_proposals -EvidenceBasename consistency_local_ai_contracts_evidence -MultistepBasename consistency_local_ai_contracts_multistep -MultistepProposalBasename consistency_local_ai_contracts_multistep_proposals -MultistepEvidenceBasename consistency_local_ai_contracts_multistep_evidence'
```

## Required validation after run

Run:

```powershell
python -m Tools.validation check_repository_change_proposals `
  --repo-root . `
  --proposal .\output\local_ai_runs\<actual-run-dir>\pipeline\consistency_local_ai_contracts_proposals.json `
  --output .\output\validation\consistency_local_ai_contracts_proposals_contract.json

python -m Tools.validation check_github_evidence_bundle `
  --repo-root . `
  --output .\output\validation\github_evidence_bundle.json

python -m Tools.validation check_validation_report_contract `
  --repo-root . `
  --output .\output\validation\validation_report_contract.json

git diff --check
```

Replace `<actual-run-dir>` manually with the generated run directory name. Do not paste `<actual-run-dir>` literally into PowerShell.
