# Apply Agent Review Doc Patch Plan

This task applies the documentation-only manual-review patch plan generated after PR #101.

## Required reading order

Read these files before planning or editing:

```text
AGENTS.md
docs/LOCAL_AI_RUN_BOOTSTRAP.md
docs/LOCAL_AI_TASKS/README.md
output/patch_specs/agent_review_patch_plan.json
output/patch_specs/agent_review_patch_plan.md
```

If `output/patch_specs/agent_review_patch_plan.*` is missing, regenerate it with:

```powershell
python .\Tools\ai\build_agent_review_patch_plan.py `
  --repo-root . `
  --orchestrator .\output\ai_pipeline\agent_gpu_npu_parallel_orchestrator_live.json `
  --evidence .\output\ai_pipeline\agent_review_evidence_sufficiency.json `
  --output .\output\patch_specs\agent_review_patch_plan.json `
  --markdown-output .\output\patch_specs\agent_review_patch_plan.md
```

## Task objective

Apply only the low-risk documentation patch plans generated by `agent_review_patch_plan`.

Expected current plan state:

```text
kind: agent_review_patch_plan
passed: true
patch_plan_count: 12
fallback_used: true
gpu_recommendation_count: 0
evidence_ready_for_manual_patch_count: 12
manual_review_required: true
```

## Allowed target files

Only these files may be modified:

```text
docs/AI_ONBOARDING.md
docs/AI_REFERENCE_ONBOARDING.md
docs/AI_REFERENCE_SOURCE_MAP.md
docs/CODE_CONSULTATION_REPORT.md
docs/LOCAL_AI_CORE_TOOL_ACTIVATION.md
docs/JSON_SCHEMAS.md
Tools/validation/README.md
```

## Required edit policy

Make small documentation-only edits.

Allowed changes:

```text
fix stale Markdown/code references
normalize references to existing docs/tools
add narrow cross-references
clarify that GPU planner can produce zero recommendations and fallback patch-plan builder is the safe next layer
document manual-review-only patch-plan behavior
```

Do not create runtime code from a documentation fallback candidate.

Do not duplicate large contract sections. Prefer short links or short summaries pointing to canonical files.

## Hard exclusions

Do not modify:

```text
output/**
indexAI/**
renders/**
SQLite databases
full analysis JSON
Blender runtime scripts
provider model/prompt/temperature/orchestration behavior
generated semantic indexes
```

Do not execute Ollama/OpenVINO/GPU/NPU providers.

Do not apply repo patch specs automatically.

Do not merge to master.

## PR report requirements

The PR body or final report must include:

```text
changed files
summary per file
validation commands and pass/fail results
provider execution statement
patch application statement
guardrail statement
risks
follow-up recommendations
```

Provider execution statement must be:

```text
Provider execution performed: false
```

Patch application statement must be:

```text
Patch application performed: manual documentation edits only; no automatic patch runner.
```

## Stop conditions

Stop and report instead of editing if:

```text
patch plan artifact is missing and cannot be regenerated
target files differ substantially from the evidence context
the required fix would touch runtime code
the fix requires provider execution
the fix requires generated index edits
the fix requires output/** or SQLite changes
```
