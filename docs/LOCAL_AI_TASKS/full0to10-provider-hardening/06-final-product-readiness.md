# Final product readiness

La readiness del prodotto finale è separata dalla readiness di run reale.

## Product review

Può passare quando:

- evidence index completo;
- SQLite FTS5 evidence presente;
- provider contracts presenti;
- tool telemetry presente;
- quality product presente.

## Real provider run

Resta bloccata finché non sono puliti:

- quality stack;
- workload report quality;
- GPU/Ollama readiness;
- NPU/GPU.0 contract;
- no source-side generated artifacts.
