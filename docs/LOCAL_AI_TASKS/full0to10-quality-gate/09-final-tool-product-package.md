# Final tool product package

Il quality gate deve trattare il pacchetto prodotto finale come output qualitativo
primario.

## Deve includere

- manifest;
- evidence index;
- readiness score;
- provider hardening;
- SQLite memory product;
- runtime tool telemetry.

## Non deve includere

- DB SQLite versionati;
- output provider generati implicitamente;
- patch applicate;
- render o media runtime.
