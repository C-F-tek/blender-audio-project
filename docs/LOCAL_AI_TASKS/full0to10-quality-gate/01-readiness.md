# Readiness

Il quality gate valuta:

- script richiesti presenti;
- report qualità visibili;
- assenza di `.md.split/` accanto ai sorgenti;
- patch-spec utili disponibili;
- blocchi prima della run reale.

La run reale Full0To10 deve partire solo quando il gate è pulito o i warning sono
accettati esplicitamente.
