# Full0To10 runtime tool registry

Il registry espone tool runtime piccoli e dichiarativi senza gonfiare il broker
principale.

## Entry point

```text
Tools/ai/full0to10_runtime_tool.py
```

## Tool iniziali

- `memory_init`;
- `memory_add_text`;
- `memory_add_file`;
- `memory_search`;
- `memory_embed_missing`;
- `memory_manifest`.
